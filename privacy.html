プライバシーポリシー

最終更新日：2026年11月13日

本ポリシーは、soft-amrita が個人で使用するローカルツール「owarai-shorts」のYouTube連携機能と、この説明サイトについて定めます。

1. 取得・送信する情報

  • Google OAuthによる認可情報（アクセストークン・更新トークン・有効期限・許可された権限）。Googleのパスワードは取得しません。
  • 連携先のチャンネルID・チャンネル名、再生リストと動画のID、タイトル、説明、タグ、公開設定、処理状況など、投稿管理に必要な情報。
  • 利用者が投稿を指定した動画・サムネイル・タイトル・説明・タグ・公開日時。これらをYouTube API Servicesを通じてGoogleへ送信します。

2. 利用目的

情報は、連携先の確認、動画のアップロード、公開設定、サムネイル・説明・タグの設定、再生リストへの追加、処理結果の確認に使用します。YouTubeから取得した情報を広告配信、販売、信用評価、汎用AIモデルの学習に使用しません。

3. 保存場所と管理

認可情報は実行するパソコン内の連携設定ファイルに保存します。投稿に使うファイルや管理記録もローカルの作業フォルダに保存します。この説明サイトや公開ソースには認可情報を置きません。パソコンとローカルファイルへのアクセスは利用者が管理します。

動画を公開した場合、動画とその公開メタデータはYouTubeの公開設定に従って他の人が閲覧できます。

4. 第三者との共有

YouTube連携に必要な情報をGoogleに送信します。YouTubeから取得した認可情報や非公開のチャンネル情報を第三者に販売せず、広告事業者やAI学習サービスへ提供しません。YouTube API Servicesの利用にはYouTube利用規約が適用されます。Googleによる情報の取り扱いはGoogleプライバシーポリシーをご確認ください。

owarai-shorts におけるGoogle APIから受け取った情報の利用および他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

5. 連携の解除とデータの削除

Googleアカウントのアクセス権管理で「owarai-shorts」のアクセス権を削除すると、Google側の認可を取り消せます。これはローカルの連携設定を削除する操作とは別です。

アプリの連携解除機能、またはローカルの連携設定ファイルの削除で、パソコンに保存された認可情報を削除できます。保存したチャンネル情報や管理記録も、対応するローカルのプロジェクト・出力ファイルから削除してください。認可を取り消しても、投稿済みの動画は自動では削除されません。投稿済みの動画はYouTube Studioから管理・削除できます。

6. この公開サイト

このサイトでは独自のアクセス解析、広告、ログイン、問い合わせフォームを設けていません。ホスティングにはGitHub Pagesを利用しています。サイト配信に伴うGitHub側の情報処理はGitHubのプライバシーに関する声明をご確認ください。

7. お問い合わせ・変更

お問い合わせはGitHub Issuesで受け付けます。認証情報や非公開データは書き込まないでください。本ポリシーを変更した場合は、このページと最終更新日を更新します。
